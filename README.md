# Prototipo Juego

1. Clonar el proyecto con GitHub Desktop

Que abran GitHub Desktop en sus computadoras y aseguren haber iniciado sesión con sus cuentas.

Vayan al menú superior File > Clone repository...

En la pestaña URL, que peguen el enlace de tu repositorio de GitHub y elijan en qué carpeta local quieren guardarlo.

Hagan clic en el botón azul Clone y esperen a que se descarguen todos los archivos.

2. Añadir el proyecto desde Unity Hub

Regla de oro: Que no intenten abrir el proyecto haciendo doble clic en las carpetas de Windows o Mac. Deben abrir obligatoriamente el programa Unity Hub.

En la pestaña de Projects, hagan clic en el botón Add (o Open, dependiendo de la versión).

Busquen y seleccionen la carpeta principal que acaban de clonar.

3. Esperar la primera compilación

Al abrir el proyecto por primera vez, Unity se va a tardar varios minutos cargando y compilando scripts.

Esto es completamente normal y necesario. Como configuraste bien el archivo .gitignore, los archivos temporales no se subieron a la nube, así que el Unity de ellos debe reconstruir la carpeta Library desde cero para adaptarse a los componentes de sus propias computadoras. Diles que sean pacientes y no fuercen el cierre.

4. Cargar la escena de trabajo

Una vez que el editor abra, es casi seguro que verán la pantalla azul vacía (el mismo susto que te pasó a ti antes).

Solo tienen que ir a la ventana Project (abajo), entrar a Assets > Scenes y hacer doble clic en el archivo de tu escena (el que se llamaba Prototipo Juego).

Al hacer eso, aparecerá inmediatamente el Canvas, el panel de diálogos, los botones y toda la conexión con el código que tú dejaste armada.
